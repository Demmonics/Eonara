# LyricMotion lyric sources

- `lookupLyrics({ title, artist, album?, durationMs? }, { signal?, cache?, force?, estimate? })` queries LRCLIB’s public v1 API. It uses title/artist plus album and duration when supplied, rejects mismatched recordings, and avoids guessing between conflicting editions. An aborted lookup rejects with the signal’s reason; missing lyrics and service errors return `quality: 'unavailable'` with explanatory messages. Use `force: true` to refresh a cached result.
- `parseLyrics(text, format, { durationMs? })` accepts `lrc`, `standard-lrc`, `enhanced-lrc`, `plain`, `ttml`, or `lyricsfile`. TTML uses the webview XML parser and supports media-time text and inline timings, not every subtitle feature. LRC positive offsets display earlier; Lyricsfile `offset_ms` is not interpreted because the draft does not specify its meaning.
- `estimateLyrics(result, durationMs)` or `lookupLyrics(track, { estimate: true })` explicitly opts in to `quality: 'estimated'` for plain lyrics. Estimation does not analyze audio and is not stored. Real word timing is present only on lines that have a coherent word/segment list; even a `word` result may include line-only cues.
- LRCLIB requests send the track metadata above, not audio or a media-service account. Tauri needs `https://lrclib.net` in `connect-src`. Set `VITE_LRCLIB_CLIENT` to the application name and version with a real project URL or contact address before distribution. `VITE_LRCLIB_APP_ID` is optional and public; never embed API secrets. Requests are serialized and rate-limited, with bounded retry and `Retry-After` handling.
- LRCLIB results use a device-local cache bounded to 60 tracks and about 900 KB. Results expire after 48 hours, confirmed misses after 15 minutes, and transient errors aren't stored. Use `clearLyricsCache()` to delete the app's stored cache or `{ cache: false }` to bypass it for a lookup. Other metadata and settings are not affected.
- Lyrics may be copyrighted. Provider access is not a license to redistribute them. Check provider terms and applicable rights before distribution; do not bundle, publish, or rehost cached lyrics.

Requires the `yaml` package for the Lyricsfile 1.0 draft. Run unit tests with `npm test -- src/lyrics`. To run the DOM-dependent TTML tests, open `/src/lyrics/ttml.test.html` on the Vite dev server.
